# Student_Result_Manager

## About the Project

The Student Result Management System is a simple, menu-driven application developed using Python. This project is designed to manage student records and check their academic results in an easy and organized way.

The application allows users to add student names and marks, view all registered student records, and check individual student results. It uses a Python dictionary to store student names and their marks, making it easy to access and manage student information.

The program provides four options through a menu:
1. Add Student – Allows users to enter a student's name and marks and save the record.
2. View Student – Displays all the student records stored in the system.
3. Check Result – Allows users to search for a student by name and check their result.
4. Exit – Closes the application.

The system checks student marks using conditional statements. If a student's marks are 40 or above, the result is displayed as "Pass". Otherwise, the result is displayed as "Fail".

This project is developed as a beginner-level Python project to understand programming fundamentals and improve logical thinking and problem-solving skills.

## Key Features
- Add student names and marks.
- Store records using Python dictionaries.
- Display all student records.
- Search for students by name.
- Check Pass/Fail status.
- Simple menu-driven interface.
- Continuous execution using a while loop.
